入力

Tab 補完確定 / Ctrl+Space 候補表示 / Esc 候補を閉じる / Alt+R やり直す

入力補助の設定

Codium 実機に寄せるほど実戦的に、切るほど純粋な打鍵練習になります。

  • 打ち始めると候補が出ます。Tab / Enter で確定。
  • 切ると Ctrl+Space を押したときだけ出ます。
  • VS Code の既定はオン（editor.acceptSuggestionOnEnter）。実機に完全に合わせたいときだけ入れてください。オンだと候補が開いたまま Enter を押しても改行されず、以降の行がずれます。
  • li → list(map(int, input().split())) など。
  • ( を打つと ) が入り、閉じ括弧は打ち抜けます。
  • : の次行で字下げ、return などの次行で戻ります。
  • 右端の俯瞰表示。

記録の持ち出し

別の端末に自己ベストを移すときに使います。読み込みは上書きではなく、課題ごとに良いほうの記録だけが残るので、どちらの端末から先に取り込んでも同じ結果になります。

自分のコードで練習

普段使っているテンプレートや、コンテストで詰まったコードを貼ってください。タブは 4 スペースに変換されます。
